# Utensilio para limpiar manchas

**Qué es:** ahora las manchas de grasa se limpian manteniendo F, sin utensilio. Más adelante podría hacer falta una fregona o un trapo.

**Por qué molaría:** limpiar se vuelve una tarea con herramienta, como cocinar con las pinzas, y obliga a decidir entre cocinar o limpiar.

**Cómo encaja con el [[Core loop]]:** entra en el paso 4, "Gestionar". Mientras la comida se hace, toca mantener el patio limpio para no resbalar con la comida en la mano.
