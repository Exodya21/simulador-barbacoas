# Coger con clic mantenido

**Decisión:** con las pinzas, apuntas a un objeto y mantienes el clic izquierdo para cogerlo, como si apretaras las pinzas. Al soltar el clic, sueltas el objeto. Lo pidió el usuario: "apuntas a un objeto y haces clic izquierdo para cogerlo y mantienes el clic para simular que estás apretando las pinzas, y cuando sueltes el clic sueltas el objeto". Se quita el clic derecho sin coger nada, que daba la vuelta al instante: ahora la vuelta se da con el [[2026-11-23 Minijuego de dar la vuelta|minijuego]]. Commit `3dfc4cf` en `dev`.
