# Repositorio GitHub con tres ramas

**Decisión:** repo privado en GitHub con `main` (producto probado), `dev` (trabajo diario) y `documentacion` (esta bóveda de Obsidian).

**Motivo:** separar lo que funciona de lo que está en desarrollo, y tener la memoria del proyecto en la nube con historial, sin pagar Obsidian Sync.
