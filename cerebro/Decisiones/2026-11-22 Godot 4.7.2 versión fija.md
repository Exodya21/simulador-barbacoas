# Godot 4.7.2 como versión fija del proyecto

**Decisión:** la versión fija del proyecto pasa de Godot 4.6.3 a **Godot 4.7.2**. Todo el equipo usa la misma versión y el proyecto ya no debe abrirse con 4.6.3. Commit `b8ba691` en `dev`, "Pasar el proyecto a Godot 4.7.2".

**Sustituye a:** [[2026-11-22 Godot 4.6.3 versión fija]]

**Qué se hizo:**
- Se abrió el proyecto con 4.7.2 y `project.godot` pasa a la feature "4.7".
- El importador de 4.7 reescribió 260 archivos `.import`, solo para añadir opciones nuevas (`deduplicate_surfaces`, `texture_map_mode`…).
- README y `CREDITS.md` dicen ahora 4.7.2.
- La prueba de humo headless pasa con 4.7.2 sin errores de script. Falta probarlo en el editor.

**Motivo:** el usuario prefiere la versión más reciente de Godot, y la prueba no muestra problemas con Cogito 1.2.0.

**Riesgo:** Cogito 1.2.0 está hecho para 4.6.3 y sus autores no lo garantizan en 4.7. Si algo de Cogito falla en el editor, lo primero es comparar con 4.6.3.

**Regla:** todos con la misma versión. Con otra, Godot reescribe los `.import` y salen cambios cruzados en git.

**Alternativas descartadas:** quedarse en 4.6.3, la versión oficial de Cogito y la más segura.
