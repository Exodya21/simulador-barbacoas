# Sin Git LFS por ahora

**Decisión:** de momento no se usa Git LFS. Se vuelve a valorar cuando entren los `.glb` y el audio propios.

**Motivo:** Cogito ocupa unos 52 MB y entra bien en git normal. LFS en GitHub tiene cuota (1 GB gratis) y migrar después es fácil para assets nuevos.

**Alternativas descartadas:** activar LFS ya.
